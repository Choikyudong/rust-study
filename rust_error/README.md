# Rust와 에러
1. 러스트는 예외(Exception)이 없다.
2. 복구 불가능한 상황은 `painc!` 매크로를 이용해 처리한다.
3. `painc!`시 `되감기` 또는 `그만두기`를 선택하여 사용할 수 있다.  
   되감기 : 스택을 거꾸로 훑으며 데이터를 청소 (오버헤드가 존재)
   그만두기 : 프로세스 즉각 종료 후 운영체제가 메모리 정리
4. 원하는 방식을 선택하여 Cargo.toml에 다음과 같이 입력한다.
   [profile.release]
   panic = 'abort' <-- 그만두기
   panic = 'unwind' <-- 되감기
5. Result<T, E>는 복구 가능한 상황일 때 사용한다.
6. `match`와 `클로저(unwrap)`를 이용하여 다채롭게 설정할 수 있다.
7. 에러 전파를 하기 위해서는 Result를 반환한다.
8. `?` 연산자로 에러 전파를 간단하게 할 수 있다.
   해당 연산자는 반환값이 Result와 Option에만 사용이 가능하다.
