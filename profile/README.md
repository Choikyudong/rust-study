# 프로필 설정과 문서
1. 러스트에는 릴리즈 프로필을 가지고 코드 컴파일 옵션을 제어할 수 있다.
2. cargo build --[profile] 로 지정하여 사용할 수 있으며 기본값은 `dev`이다.
3. 추가를 하기 위해서는 `Cargo.toml`에 [profile.*] 섹션을 명시적으로 추가하여 사용한다.
4. 의존성들은 [create.io](https://crates.io/)를 이용해 받거나 배포를 할 수 있다.
5. 문서화 주석은 `///` 로 작성할 수 있다. 작성한 문서는 cargo doc --open으로 조회할 수 있다.
6. //!를 이용해 모듈에 대한 문서를 작성할 수 있다.
