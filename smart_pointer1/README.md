# 스마트 포인터
1. 스마트 포인터란 일반적인 포인터와 다르게 주소 값 + 소유 여부 등을 가진 포인터이다.
2. 가장 직관적인 스마트 포인터는 `Box<T>` 타입이다.  
   `Box`는 스택이 아닌 **힙**에 데이터를 저장한다.  
3. `Box`는 다음과 같은 상황에 자주 사용된다.
   - 컴파일 타임에는 크기를 알 수 없는 타입일 때 (예시: 재귀형)
   - 커다란 데이터의 소유권을 옮기고 싶고 그렇게 할 때 데이터가 복사되지 않음을 보장하고 싶을 때
   - 특정 트레이트(**trait**)를 구현한 타입이라는 점만 신경쓰고 싶을 때
4. `*<변수>`를 통해 역참조를 할 수 있다.  
   역참조를 하게 될 때는 `deref`메서드를 이용하여 참조할 수 있다.
5. `drop`을 이용하여 스코프가 끝나기전에 값을 버릴 수 있다.  
   다만 `.drop()`을 명시적으로 호출하지는 못하게 한다.   
   `drop`을 이용하고 싶다면 `std::mem::drop`을 이용해야 한다.
   `.drop`을 이용하지 못하는 이유는 스코프가 끝날 때 `.drop`을 자동호출하는데 그 때 중복 해제 에러가 될 수 있기 때문이다.
