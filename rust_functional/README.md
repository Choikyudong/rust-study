# 러스트와 함수형 프로그래밍
1. 러스트도 함수형 프로그래밍을 지원한다.
2. #[derive] 로 코드 생성기 역할을 줄 수 있다. (함수형과 상관은 없음)
3. 클로저란 주변의 변수를 저장하는 익명 함수이다.
4. ||로 사용할 수 있다.
   ```rust
   함수 : fn add_one(x: u32) -> u32 { x + 1 }
   클로저 : |x : u32| x + 1
   ```
5. 클로저는 일반 함수와 달리 함수 밖의 변수를 마음대로 사용할 수 있다.
   ```rust
   let x = 4;
   let equal_to_x = |z| z == x; 
   ```
